# Documentación administrativa

Coloca aquí el **Anexo I firmado** (declaración de originalidad, uso de IA y
autorización del director) con el nombre `AnexoI_firmado.pdf` y activa
`\AnexoItrue` en `memoria/config/datos.tex`. La memoria lo insertará entre
las dos portadas, como exige la normativa.

Descarga siempre el formulario **vigente** desde la web o la plataforma de la
escuela: cambia de un curso a otro.

> Este directorio se versiona. Si el repositorio es público, piensa si
> quieres subir documentos con firmas. Lo recomendable es que el
> repositorio del TFG/TFM sea **privado**.
